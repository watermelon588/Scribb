# Welcome animation

Source supplied by the project owner, retained at the repository root:
`From Klickpin.com- Cozy bridesmaid dress inspiration that are trending right now and still timeless enough to save for later for anyone planning a.gif`.
The source filename is provenance, not an instruction or an attribution claim.
No generated imagery was used.

The 1080 × 608, 3.76-second GIF was converted with FFmpeg to 720 × 406 H.264,
CRF 22, yuv420p, fast-start MP4 with no audio. Only the connected white background
at pixel (0, 0) was flood-filled in planar GBR before scaling:

- Light: RGB (250, 249, 246), matching `--app-bg`.
- Dark: RGB (24, 28, 26), matching `--app-bg`.

Foreground white areas such as eyes are preserved. Each theme has a first-frame
WebP poster. Original artwork, motion, aspect ratio and timing are retained.
